2. 01 сдвинулось вправо т.к. в little-endian младший байт хранится первым. 
3. Потому что не хватает 16 бит для написания.

Кол-во символов и кол-во байтов может отличаться из за разного языка и длинны текста. 
 
Eng "A" -> 41 
Rus "А" -> D0-90
